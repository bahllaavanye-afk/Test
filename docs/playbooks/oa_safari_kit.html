QuantEdge — Options Alpha Export Kit (Safari)

One-time setup, then one tap on any OA page exports what's on screen (bot list, a bot's settings, community templates) as JSON — copied to your clipboard and shown in a box.

1 · Install the bookmarklet

Easiest (Mac): drag this button to your Favorites bar (View → Show Favorites Bar):

📦 OA → QuantEdge Export

Or manually (works on iPhone too): bookmark any page, then Edit the bookmark and replace its address with the code below (select-all inside the box → copy):

2 · Export your bots

  1. Open app.optionalpha.com/bots (logged in) and tap the bookmarklet → paste the JSON.
  2. Then open each bot you care about (its settings/detail view) and tap it again — the detail page carries the legs/deltas/DTE/exits that the list view doesn't.
  3. Repeat on /community/toptpls and /community/templates for community bots you want cloned.

The export contains only what YOUR logged-in browser rendered plus the page's local cache — no passwords, no cookies.

3 · Deliver it

Paste each JSON blob into either:

  1. a GitHub issue on bahllaavanye-afk/Test titled [oa-import] <bot name> — the import pipeline converts it to a bot template, tests it, and PRs it, or
  2. Claude chat — same result, done in-session.
